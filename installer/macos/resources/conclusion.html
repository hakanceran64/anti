Hadron Antivirus has been successfully installed on your Mac.

The background protection service is now running and your system is being monitored for threats.

Next Steps - Security Permissions

1. Grant Full Disk Access

For complete protection, Hadron Antivirus needs Full Disk Access:

  1. Open System Preferences → Security & Privacy
  2. Click the Privacy tab
  3. Select Full Disk Access from the left panel
  4. Click the lock icon and enter your password
  5. Click the + button and add Hadron Antivirus.app

2. Allow System Extension (if prompted)

If you see a system extension notification:

  1. Click Open Security Preferences
  2. Click Allow next to the Hadron Antivirus extension
  3. Restart your Mac if required

3. Launch the Application

You can now launch Hadron Antivirus from:

  • Applications folder
  • Spotlight search (⌘ + Space, then type "Hadron")
  • Launchpad

Command Line Usage

The hadron-cli tool has been installed and is available from Terminal:

hadron-cli --help
hadron-cli scan /path/to/scan
hadron-cli status

Important Notes

  • The background service starts automatically and will restart on system reboot
  • Initial signature database download may take a few minutes
  • You can check service status using: hadron-cli status
  • To uninstall, use the "Uninstall Hadron Antivirus" app in your Applications folder

Getting Help

If you need assistance:

  • Check the built-in help: hadron-cli --help
  • View logs: tail -f /var/log/hadron-antivirus.log
  • Visit our documentation or support resources
