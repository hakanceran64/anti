Key Features

System Requirements

  • macOS 10.15 (Catalina) or later
  • 64-bit Intel or Apple Silicon processor
  • At least 100 MB of free disk space
  • Administrator privileges for installation

Important Security Setup

After installation, you will need to grant the following permissions for full protection:

  • Full Disk Access: Required for comprehensive file scanning
  • System Extension: Enables real-time file monitoring
  • Network Monitoring: Optional, for network threat detection

The installer will guide you through these steps after installation completes.

What will be installed:

  • Hadron Antivirus.app - Main application in /Applications
  • hadron-cli - Command-line tool in /usr/local/bin
  • Background Service - System service for real-time protection
  • Uninstaller - Easy removal tool
